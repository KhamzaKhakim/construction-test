# Система управления строительными задачами

Веб-приложение для управления задачами на строительном объекте. Позволяет создавать, просматривать, фильтровать и удалять задачи, а также отмечать их как завершённые.

## Технологии

- **Frontend**: Next.js, React, TanStack Query, TanStack Table
- **Backend**: Elysia (через Next.js API routes)
- **Рантайм**: Bun
- **UI**: shadcn/ui, Tailwind CSS
- **Типизация**: TypeScript

## Функциональность

### Задачи

- Просмотр списка всех задач в виде таблицы
- Создание новой задачи (название, объём, ответственный)
- Удаление задачи
- Отметка задачи как завершённой (доступно только ответственному исполнителю)

### Фильтрация и сортировка

- Сортировка по дате создания (по возрастанию / убыванию)
- Фильтрация по диапазону дат создания (От / До)
- Переключатель «Мои задачи» — показывает только задачи текущего пользователя

### Простая авторизация

- Выбор текущего пользователя через селектор в шапке страницы
- По умолчанию выбирается первый менеджер из списка
- Только **менеджер** может создавать задачи
- Только **ответственный исполнитель** видит кнопку завершения своей задачи

### URL-параметры

Состояние фильтров и сортировки сохраняется в URL:

- `?sort=asc` / `?sort=desc` — направление сортировки
- `?dateFrom=YYYY-MM-DD` — начало диапазона дат
- `?dateTo=YYYY-MM-DD` — конец диапазона дат

## Запуск

### С Bun (если есть)

```bash
bun install
bun run dev
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)

### Без Bun — через Docker

```bash
docker compose up --build
```

Приложение будет доступно по адресу: [http://localhost:3000](http://localhost:3000)
